# 町のデータ探偵団

小学6年生向けの「データの活用」学習サイトです。
データを手がかりに5つの事件を解決しながら、散らばり、代表値、度数分布表、ヒストグラム、データに基づく判断を学びます。

## 対象

- 小学校6年生
- 算数「データの活用」
- タブレット、パソコンで利用可能

## 学習モード

### 基本学習モード

物語に沿って、次の5つの事件を順番に解決します。

1. 散らばりとドットプロット
2. 平均値・中央値・最頻値
3. 度数分布表
4. ヒストグラム
5. データの読み解きと結論の吟味

各章では、問題に正解しないと次へ進めません。間違えたときはヒントを確認して、同じ問題にもう一度挑戦できます。

### 名探偵への道

章を自由に選んで、5問ずつ練習できます。

- 問題は一部ランダムに生成
- 正解数に応じて探偵ランクが上がる
- 間違いが続いた問題は「にがてパターン」として記録
- 5問ごとに調査結果を確認

### バッジコレクション

ホームまたは画面上部の「🏅 バッジ」から、学習の達成を共通バッジで確認できます。

- 事件の解決、練習問題の正解数、調査の積み重ねに応じて10種類を獲得
- 獲得済みはカラー、未獲得はグレー表示
- 獲得時は学習画面に通知
- 既存の学習記録と同じlocalStorageに保存
- 画像は共通素材リポジトリ `TT-sensei/edu-assets` を参照

## 学習記録

学習記録は、利用している端末のブラウザ内に保存されます。

- 物語の進み具合
- 練習問題の正解数
- 苦手パターン
- 探偵ランク
- 事件番号

外部サーバーやデータベースには送信しません。
「探偵手帳」から学習記録を書き出したり、リセットしたりできます。

## edu-kit準拠

この教材は、edu-kitの設計原則に合わせて、学習内容を最優先にした構成で運用します。

- 学習入口、問題、主要操作、現在地を先に見せる
- 不正解のあとに、ヒント、答えを見る、再挑戦を用意する
- 答えを見たことは正答として記録しない
- 既存の学習記録キーを保ったまま、StorageManagerで保存を管理する
- edu:correct、edu:wrong、edu:progress、edu:screenchangeを画面連携の境界にする
- タブレット横向きを基本にし、補足説明だけを必要に応じてスクロールする
- 画像が読み込めなくても学習本体は継続し、reduced motionにも対応する

## NAVIキャラ

NAVIキャラは問題や答えの代わりではなく、調査の視点をそっと示す補助役として配置しています。実在確認した軽量WebPを使用しています。

- トップ: `group-learning-pair-diagram.webp`
- フィードバック: `group-learning-pair-observation.webp` / `group-learning-pair-consulting.webp`
- 参照元: `TT-sensei/navi-character-` の `assets/web/groups/learning/`
